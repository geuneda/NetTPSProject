# NetTPS - 리슨서버 기반 멀티플레이어 TPS 게임

## 프로젝트 개요
NetTPS는 언리얼 엔진 5.5.4로 개발된 리슨서버 기반의 멀티플레이어 TPS(Third Person Shooter) 게임입니다. 이 프로젝트는 네트워크 게임 개발의 핵심 개념과 언리얼 엔진의 리플리케이션 시스템을 학습하기 위한 목적으로 제작되었습니다.

## 주요 기능

### 캐릭터 기능
- **기본 이동**: 걷기, 점프 등 기본적인 캐릭터 이동
- **시점 조작**: 마우스를 통한 자유로운 3인칭 시점 조작

### 무기 시스템
- **총 획득/놓기**: 일정 거리 내의 총을 집고 놓을 수 있는 기능
- **총 발사**: 크로스헤어를 통한 조준 및 발사 시스템
- **탄약 관리**: UI를 통한 현재 탄약 상태 표시
- **재장전**: 탄약 재장전 기능 및 애니메이션

### 데미지 시스템
- **체력 관리**: 캐릭터 체력 시스템
- **피격 처리**: 총알에 맞았을 때 데미지 처리
- **사망 처리**: 체력이 0이 되었을 때 사망 처리

### 네트워크 기능
- **리슨서버 구조**: 호스트가 서버와 클라이언트 역할을 동시에 수행
- **RPC 활용**: 서버-클라이언트 간 효율적인 통신
- **변수 리플리케이션**: 게임 상태의 동기화
- **멀티캐스트**: 여러 클라이언트에 동시에 이벤트 전달

### UI 시스템
- **크로스헤어**: 총을 들었을 때 표시되는 조준점
- **탄약 UI**: 현재 남은 탄약 표시
- **체력 UI**: 캐릭터의 현재 체력 상태 표시

## 기술적 특징

### 네트워크 구조
- 리슨서버 모델 사용
- RPC(Remote Procedure Call)를 통한 서버-클라이언트 통신
- 변수 리플리케이션을 통한 게임 상태 동기화
- 네트워크 최적화를 위한 권한 모델 적용

### 언리얼 엔진 기능 활용
- Enhanced Input System을 통한 입력 처리
- Animation Blueprint를 이용한 캐릭터 애니메이션
- UMG를 활용한 UI 구현
- 언리얼 엔진의 네트워크 시스템 활용

## 구현 방법

### 총 시스템
- 월드에 배치된 총 검색 및 상호작용
- 물리 시뮬레이션을 통한 총 오브젝트 관리
- 라인 트레이스를 이용한 발사 및 히트 감지

### 데미지 시스템
- 리플리케이션을 통한 체력 동기화
- 클라이언트 및 서버 측 체력 UI 업데이트

### 네트워크 통신
- ServerRPC를 통한 서버 요청
- ClientRPC를 통한 클라이언트 응답
- MulticastRPC를 통한 다중 클라이언트 이벤트 처리

## 학습 포인트
- 언리얼 엔진의 네트워크 아키텍처 이해
- 클라이언트-서버 권한 모델의 구현 방식
- 리플리케이션 및 RPC를 통한 게임 상태 동기화
- 네트워크 디버깅 및 최적화 기법

## 개발 환경
- 언리얼 엔진 5.5.4
- C++
- Visual Studio

## 설치 및 실행 방법
1. 프로젝트 클론 또는 다운로드
2. 언리얼 엔진 5.5.4 설치
3. 프로젝트 파일(.uproject) 열기
4. 에디터에서 컴파일 및 실행

## 조작 방법
- **WASD**: 이동
- **마우스**: 시점 조작
- **스페이스바**: 점프
- **F키**: 총 획득
- **G키**: 총 놓기
- **좌클릭**: 발사
- **R키**: 재장전

## 네트워크 테스트 방법
1. 에디터에서 Play 버튼 클릭 후 Number of Players 설정
2. 또는 패키징 후 독립 실행 파일을 여러 개 실행하여 테스트

이 프로젝트는 언리얼 엔진의 네트워크 기능과 멀티플레이어 게임 개발에 대한 이해를 돕기 위한 학습용 프로젝트입니다.
